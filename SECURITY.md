# Security Policy

## Supported Versions

Security fixes are currently provided for the latest version on the `main`
branch.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately. Use GitHub's private
vulnerability reporting feature when it is enabled for this repository. If it
is not available, contact the maintainers through a private channel listed in
the repository owner's GitHub profile.

Please do not open a public issue for an unpatched vulnerability.

Include the following where possible:

- A description of the vulnerability and its potential impact
- The affected version or commit
- Reproduction steps or a proof of concept
- Any suggested mitigation

Do not include live credentials, private keys, or other sensitive data in a
report. Redact sensitive values and provide sanitized examples instead.

Reports will be acknowledged as soon as practical. Once a fix is available,
the maintainers will coordinate disclosure details with the reporter.
